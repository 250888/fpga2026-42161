## 通用前提

- Windows 10/11 + Python 3.12 + [`uv`](https://docs.astral.sh/uv/)
- 脚本路径以**仓库根目录**为基准
- 涉及 Vivado 的条目需本机已装 Vivado（本项目用 2026.1）

## 为什么这些值得复用

本项目的 16 通道外扩板是**手工焊接**的，排障占了整个开发周期的一大半；
自定义 48 字节帧协议在 RTL 与 Python 两侧各有一份实现；
报告与海报都是**按官方模板批量生成**而非手写。
这三类问题在同类竞赛项目里几乎人人都会遇到，所以把它们整理成可迁移的清单与脚本。

## 复用验证

| 项 | 验证方式 | 结果 |
|---|---|---|
| 1 踩坑清单 | 在本项目上使故障通道从 11 路收敛到 0 路 | 16/16 全通 |
| 2 黄金帧回归 | 在 B1 缺陷（帧矩阵未快照）上复现并拦截 | 抓到并回归通过 |
| 3 报告模板 | 从模板生成 13→16 页报告，含 2 张自动表格 | 通过 |
| 4 海报模板 | 生成中英各一页，含 AMD 标识与校标 | 通过 |
| 5 打包工具 | 中文文件名上位机打包后解压哈希与源一致 | 通过 |
