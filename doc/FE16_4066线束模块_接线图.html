瞬迹 / XunJi · 4066 Harness Module

CD4066 动态线束模块 · 接线图

用途：插在 FE-16 的 JA 与 JB（都是 2×10 母座）之间，把 16 路信号各串一个 CD4066 模拟开关， 由脉冲源驱动控制脚，在 µs 级把指定通道断开。JA/JB 是孔，所以模块两端都用 2×10 公头。

01 / 拓扑

16 路串接总图

每一路：JA 公头 pin(i) → 某颗 4066 的一个开关 → JB 公头 pin(i)。 4066 是双向开关，两个信号脚可互换。JA/JB 的 17–20 是 NC，不用接。

02 / 引脚表

哪一针接哪只脚（照表焊）

通道JA 针JB 针芯片开关 信号脚（两端）控制脚
CD4066 脚位（DIP-14）：1/2=SW1、3/4=SW2、8/9=SW3、10/11=SW4； 控制脚 SW1=13、SW2=5、SW3=6、SW4=12；14=VDD、7=VSS(GND)。 四颗芯片的 14 脚都接电源、7 脚都接地。
03 / 控制

控制线怎么并

方案 A · 4 根（推荐，演示够用）

每颗芯片把 13/5/6/12 并成一根：
CTRL_U1 高 → ch0–3 断；CTRL_U2 → ch4–7；CTRL_U3 → ch8–11；CTRL_U4 → ch12–15。
4 根同时高 → 16 路全断。

方案 B · 16 根（单根精确断）

16 个控制脚各引一根，可精确开任意 1 路。需要 16 个 GPIO （Arduino Mega / 两片 74HC595），接线量大但演示最像"某一根线断了"。

04 / 电源

供电与共地

  • 4066 用 5V 供电（从脉冲源/Arduino 的 5V 取），VSS 必须与 FE-16 共地（接 FE-16 的 TP50 / J5 的 33、34）。
  • 信号线是 FE-16 的 3.3V，在 0–5V 范围内，4066 照常通过，不需要电平转换。
  • 控制脚高电平 ≥ 3.5V（5V 供电时 0.7×VDD）；Arduino 5V 输出直接够。
  • 如果坚持用 3.3V 供电：控制脚也必须 3.3V 逻辑（阈值 2.3V），别用 5V 去驱 3.3V 供电的 4066。
  • 整板电流 µA–mA 级，不需要额外电源。
05 / 焊接与自检

焊完怎么验

顺序

  • 先焊 4 个 DIP-14 插座，芯片最后插（别直接焊芯片，坏了不好换）。
  • 焊两个 2×10 公头（P1 对 JA、P2 对 JB），pin1 方向一致。
  • 按表逐路飞线：P1.i → 开关 a 脚，开关 b 脚 → P2.i。共 32 根短线。
  • 并控制线（方案 A 每芯片 4 脚并 1 根），引出到 4P 排针。
  • VDD/VSS 用 2P 排针引出。

不用上电就能验

  • 控制脚接 3.3V/5V：万用表蜂鸣档测 P1.i ↔ P2.i，16 路都该通。
  • 控制脚接 GND：16 路都该断（不响）。
  • 哪一路不对，就查那一路的开关脚或飞线。
  • 再用示波器确认：控制脉冲宽度 → 线束断开宽度一致（如 10µs）。
别用它测接触电阻：4066 导通电阻约 50–200Ω，会叠加在线束上。 它只负责"通/断"和"何时断"，不负责测阻值。
按 CD4066B（DIP-14）标准脚位绘制 · 与 FE-16 的 JA/JB（2×10 母座，1–16 信号）对应。
