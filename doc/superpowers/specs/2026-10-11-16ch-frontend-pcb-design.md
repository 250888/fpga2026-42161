# 瞬迹 16 路前端 PCB 设计文档（FE-16）

- 日期：2026-10-11
- 状态：待用户批准
- 权威依据：《瞬迹_完整可行技术路线_EGO1开发板版_V1.9.docx》§4/§5/§9/§9.1、TABLE 3（J5 映射）、TABLE 6（采购）、TABLE 13（PCB 设计要点）、TABLE 14（A/B 针序）

## 1. Intent / 为什么画这块板

步骤一（1 路）与步骤二（4 路）在洞洞板上验证通过后，按 V1.9 §9 制作 **16 路正式前端板**：EGO1 经 36 芯转接线接入本板，本板完成 A 端开漏激励（LVC07）、B 端上拉+施密特整形（LVC14），把 16 路被测线束的通断状态还原为 `b_raw[15:0]` 交回 FPGA。板子为比赛演示与实测标定服务，**可调试性优先于体积**。

## 2. Goals / Non-goals / Anti-goals

**Goals**
- 16 路完整前端，一次画对：针序、语义与 V1.9/XDC/RTL 一一对应。
- 两层板，底层连续 GND；全部关键节点可挂示波器。
- B 端 Rp、A 端串联保护电阻均留**可替换位**（参数实验是项目核心方法论）。
- 产出可直接送打样的 KiCad 工程 + BOM + 机检报告 + 渲染预览。

**Non-goals（本板不做）**
- 4066 故障发生器（V1.9 步骤五，独立板）。
- 第一版默认 J5 同源取 3.3V（V1.9 §9）；但正式板须按 V1.9 TABLE 6「保留可断开测试点」设整板电流断点与互斥备用入口（D15），因 §5 要求上电前实测整板电流。
- 接触电阻/模拟前端/保护到汽车电压等级（V1.9 §6 明确不买不做）。

**Anti-goals（明确禁止）**
- 不把 3.3V/GND 引入 A/B DUT 接口 1-16 脚；17-20 必须 NC/KEY。
- 不悬空任何 CMOS 输入（LVC07 未用输入固定高、LVC14 未用输入固定低/高、4066 不在本板）。
- 不改动 V1.9 冻结内容：J5 针序、`a_ctrl_n` 极性语义、`b_conn=1 导通` 语义、NC 定义。
- 不追求最小体积、不做阻抗控制（直流/低速数字）。

## 3. Constraints（来自 V1.9，不可改）

1. **J5 映射**（TABLE 3）：J5-1..16 = `a_ctrl_n[0..15]`（→LVC07 输入），J5-17..32 = `b_raw[0..15]`（←LVC14 输出），J5-33/34=GND，J5-35/36=3.3V。丝印与 XDC/RTL 编号一一对应。
2. **极性语义**：`a_ctrl_n=0` → LVC07 拉低线束；`=1` → 释放（高阻）。真实前端下导通 `b_raw=1`、开路 `b_raw=0`（LVC14 反相恰好完成此映射，板上不再加反相）。
3. **上电安全**：每个 LVC07 输入带 10kΩ 上拉到 3.3V，FPGA 未配置时 A 端默认释放。
4. **A/B 接口**（§9.1/TABLE 14）：2×10 20Pin，A/B 针序完全相同，1-16=信号，17-20=NC/KEY（不接任何网络），20 芯排线红边=Pin1。
5. **Rp**（§9/TABLE 9）：每路可替换，首版默认 4.7kΩ，另备 1k/2.2k/10k；B 端单路 0.70mA@4.7k。
6. **保护**（TABLE 13）：A 端每路预留串联电阻位，首板 330Ω 起步（220Ω 备选）。
7. **未用通道**（§9）：3×LVC07=18 通道用 16，剩 2 输入固定高；3×LVC14 同理剩 2 输入固定 GND 或 3.3V。
8. **电源**（§9）：J5 同源 3.3V，入口 10μF 总旁路，每 IC 100nF 去耦；上电前必须整板实测电流核对 J5 余量（文档要求，非设计动作）。
9. **两层板、底层连续 GND、尺寸稍大、标注清楚**（§9 原文）。
10. **测试点**（§9/TABLE 13）：A 节点、B 模拟节点、b_raw（LVC14 输出）、3.3V/GND 均留测试点，每路一个。

## 4. Decisions（我拍板的 how，标 ⓒ 为可改的 call）

|---|---|---|
| D1 | EDA | **KiCad 8 格式**，s-expression 文本程序化生成（本机无 KiCad，不依赖 GUI）；立创 EDA 专业版可导入下单。ⓒ |
| D2 | 产出 | `pcb/frontend16/`：`.kicad_sch` + `.kicad_pcb` + `BOM.csv` + 生成脚本 + SVG 渲染预览 + pytest 机检 |
| D3 | 板框 | **96×96 mm**（2026-10-13 由 160×90 缩板：用户「最好 <10×10cm，嘉立创免费券」），四角 φ3.2 安装孔（NPTH）。ⓒ |
| D4 | 布局 | 上边=J5 2×18 牛角座；左边=A 端 2×10 牛角座+LVC07×3+串联电阻；右边=B 端 2×10 牛角座+Rp×16+LVC14×3；测试点分区排布 |
| D5 | 接口连接器 | PCB 端三只 **2.54mm 2×N 牛角座（box header）**，孔位与同距双排针完全兼容（用户已购连接器公母未确认时两种都能焊）。ⓒ |
| D6 | IC 封装 | **SOIC-14（贴片）**：SN74LVC07ADR ×3、SN74LVC14ADR ×3（采购含 SOP14 转 DIP 板，推断手里为贴片）。ⓒ 需用户确认 |
| D7 | 无源 | 0805：16×10k（LVC07 输入安全上拉）、16×330Ω（A 端串联）、16×4.7k（Rp，可替换）、6×100nF（IC 去耦）、1×10μF（J5 入口）；未用输入按 D8 直连电源轨，无额外电阻 |
| D8 | 未用通道绑定 | U3（LVC07）通道 16/17：输入直连 3.3V、输出悬空；U6（LVC14）通道 16/17：输入直连 GND、输出悬空。丝印标注 NC-USE。ⓒ |
| D9 | 通道分配 | U1=LVC07 ch0-5、U2=ch6-11、U3=ch12-17（用 12-15）；U4=LVC14 ch0-5、U5=ch6-11、U6=ch12-17（用 12-15）。与丝印 A01-A16/B01-B16 对应 |
| D10 | 走线 | 信号 0.25mm；3.3V 主干 ≥0.5mm；底层整面 GND（铺铜），顶层信号+局部 3.3V；参数化"通道带"走线模板，全板 100% 布通（不留飞线） |
| D11 | 测试点 | φ1.0mm 通孔测试环：TPA0-15、TPB0-15、TPR0-15（b_raw）、TP3V3、TPGND，共 50 个。ⓒ 可裁减 |
| D12 | 网络命名 | `ACTRL0..15`（J5→LVC07 入）、`ADRV0..15`（LVC07 出→串阻→A 口）、`A0..15`（A 口侧节点，串阻后）、`B0..15`（B 口→Rp→LVC14 入）、`BRW0..15`（LVC14 出→J5）、`VCC3V3`、`GND`；A/B 口 17-20 无网络 |
| D13 | 丝印 | 板名 `XunJi FE-16 V1.0` + 队名；每通道标 `A01/J5-1`、`B01/J5-17` 式双标号；Pin1 三角；接口名；NC/KEY 警示；安装孔标记 |
| D14 | 电源预算（写入 BOM 注释，打样前实测） | Rp 全导通 11.2mA + 安全上拉 5.3mA + IC 动态 ~12mA + 余量 → 估算 <50mA，J5 余量上板前实测 |
| D15 | 电源断点/备用入口 | 落地 V1.9 TABLE 6「正式PCB保留可断开测试点，不允许同时短接两路电源」：J5 3.3V 入口后串 0Ω 断点位 R_CT，两侧出测试环 TP_VIN/TP_VCC（电流表直接跨接测整板电流）；另留 2 针外部 3.3V 备用焊盘 EXT，经 3 脚跳线 JP1 互斥选择 J5/EXT，丝印「禁止同时短接两路电源」 |

## 5. Verification（怎么算画对了）

1. `tests/test_frontend_pcb.py`（pytest，随生成脚本一起提交）：
   - 网表断言：每个 IC 引脚→网络与 D9/D12 预期表逐一相等；
   - 针序断言：J5/A/B 三连接器 1-36/1-20 针→网络与 V1.9 TABLE 3/14 一致；A/B 口 17-20 无网络；
   - 安全断言：LVC07 全部 18 输入有网络（16 路 ACTRL + 2 路 VCC3V3）；LVC14 全部 18 输入有网络（16 路 B + 2 路 GND）；未用输出无网络；
   - 无源数量断言：R/C 位号与 D7 清单一一对应；
   - 几何断言：同层异网线段间距 ≥0.2mm、线在板框内、焊盘不互撞、无重复位号；
   - 布通断言：全部信号网络的焊盘经走线几何连通（无 ratsnest 残留）。
2. SVG 渲染（顶/底层 + 丝印）→ HTML 预览页给用户过目。
3. KiCad 打开性：s-expression 语法由生成器单测覆盖；用户可用 KiCad 8 或立创 EDA 专业版打开复查（本机无 KiCad，不做 GUI 级验证）。
