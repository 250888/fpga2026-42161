03 / 效果

拓扑判定 · 实时演示

这是板上 golden_compare 的逻辑在浏览器里的同一套算法：先 LEARN 出参考矩阵，再逐路扫描比对，输出 Missing / Extra 与连接度，最后落到判定。 参考线束是 1:1 双射（LEARN 只接受行列连接度均为 1 的参考），因此实际可复现的是 PASS / OPEN / MISWIRE / BRIDGE 四类；ANOMALY 只在参考本身非双射时才出现。

04 / 接线

整机物理接线与测试电路

把成品放回整机：EGO1 主控 → 2×18 排线 → FE-16 → 被测线束（串 CD4066 故障源）→ 回板；示波器三只探头夹在驱动 / 线束 / 整形回读三个测试点上。拖动可旋转。

拖动 旋转 · 滚轮 缩放

连接关系

EGO1 J5 ↔ FE-16 J52×18 排线，1:1；1–16 驱动、17–32 回读、33/34 地、35/36 3.3V（板子供电也走这里）
FE-16 JA / JB被测线束 A 端 / B 端（20P，1–16 信号，17–20 NC）
线束中间CD4066 四路模拟开关 ×4，串入 16 路，µs 级开路注入
脉冲源驱动 CD4066 控制脚，产生可调宽度的断开脉冲
示波器 CH1/2/3三点观测：TP(1+n) 驱动 → TP(17+n) 线束 → TP(33+n) 整形回读
USBEGO1 供电 + 烧录 + 串口

接线的三个硬约束

  • 只有一路电源：EGO1 经 J5 的 35/36 给 FE-16 供 3.3V，别再外接第二路 3.3V（EXT1 与 RCT1 互斥）。
  • 探头先接地：地夹先接 TP50（GND），再夹信号点，否则共地噪声会淹掉 µs 脉冲。
  • 三点同触发：三通道用同一触发源（驱动下降沿），才能对齐"驱动—线束—回读"的时序。
