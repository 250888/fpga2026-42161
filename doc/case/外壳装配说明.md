## 2. 总体尺寸

**274 × 176 × 45 mm**（底壳 42 + 上盖 3），壁厚 3，底厚 3。

### 内部布局（板坐标，原点在外壳左下角）

```
 y=0  ┌──────────────────────────────────────────┐
      │      后侧线缆槽 22mm（2×18 排线 / 电源）    │
 y=25 ├──────────────────┬───────────────────────┤
      │                  │  ┌───┐                │
      │   EGO1 舱位       │  │FE-16│  ← M3×4 柱   │
      │   150 × 100       │  │96×96│               │
      │  （围边定位，      │  └───┘                │
      │   不依赖安装孔）   │                       │
      │                  │   DUT 线束回路区 40mm   │
 y=165├──────────────────┴───────────────────────┤
      │         前侧开口（线束引出 + 取景）         │
 y=176└──────────────────────────────────────────┘
```

- **EGO1 舱位**：`(8, 32)` 起，150×100；四周 2.5mm 围边、5mm 高，**不需要板上有安装孔**。
  实测尺寸不同只改脚本里 `EGO_W / EGO_H` 两行。
- **FE-16 舱位**：`(170, 32)` 起，96×96；**4 个 M3 支撑柱**，柱位 = 板坐标 (4,4)(92,4)(4,92)(92,92)，
  柱顶 z=6（板下留 3mm 给背面焊点），2.6mm M3 自攻底孔、深 6。
- **后侧线缆槽**：22mm 深，隔墙 2mm，FE-16 的 J5 正对处开 52mm 过线口。
  **排线全程在壳内走，不穿壁、不折 180°**。
- **DUT 线束回路区**：FE-16 前方 40mm 空区，JA→JB 的线束从这绕。
  前侧开口 116mm 宽，线束引出、镜头取景、示波器探头都从这里。
- **通风槽**：左侧 4 条、前侧 2 条（不影响线束）。
- **底面四角**：Ø8 × 1.2 深脚垫槽。

## 3. 上盖

- 3mm 平板 + 2mm 凸缘（插入底壳内腔，摩擦配合，**不用螺丝**）。
- 中央窗口 254 × 156，四周 10mm 边框。
- 窗口内圈留 **2mm 深 × 4mm 宽承台**，装 2mm 亚克力（透光看 LED / 七段数码管 / FE-16 状态）。
- 亚克力另配：激光切割 **254 × 156 × 2mm**，用双面胶或 4 点 UV 胶固定。

## 5. 打印参数

- 材料：**PETG**（推荐）或 PLA+；不要用普通 PLA（夏天车内变形）。
- 层高 0.2mm，壁数 3，填充 20%（gyroid）。
- 支撑：底壳的线缆槽隔墙与前侧开口有悬空 → **树状支撑仅接触热床**；上盖无需支撑。
- 打印方向：底壳**底面朝下**；上盖**外面朝下**（窗口承台朝上，避免支撑）。
- 底壳约 190 g，上盖约 55 g（PETG 1.27 g/cm³ 估算）。

## 6. 装配顺序

1. 底壳四角贴脚垫。
2. EGO1 放入舱位（底部垫泡棉/双面胶），靠围边定位。
3. FE-16 用 4× M3×10 + 垫圈拧到支撑柱上（**先不拧死**）。
4. 插 J5 2×18 排线：从线缆槽过线口穿到 EGO1 的 J5，**排线留一段松弛**再理进槽。
5. 接 DUT 线束到 JA/JB，线束回路放进前方开区。
6. 上盖从上压入（凸缘进内腔），亚克力从内侧贴到承台上。
7. **上电前**再确认：排线红线对 pin1、JA/JB 没接反、TP50 与 TP49/TP51 不短。
