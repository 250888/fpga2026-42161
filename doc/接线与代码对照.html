35/36 是 3.3V、33/34 是 GND——不进 XDC、不接 I/O。36 芯转接线压好后，先万用表逐线核对丝印/线标再上电；电源误进 I/O 是这台设备最贵的一种错法。

板级接口注记

  • 系统时钟全片只有 100 MHz sys_clk（P17），没有第二时钟域；扫描节拍、去毛刺、波特率全部用 clock-enable 派生。
  • 复位FPGA_RESET/S6 = P15，4.7kΩ 上拉、按下接地 → 低有效 rst_n；按下立即进复位，松开只在时钟沿同步解除（xj_rst_sync）。
  • USB-UART板载 T4 = FPGA 发、N5 = FPGA 收，115200 8N1。蓝牙串口是 N2/L3（BLE-CC41-A），别接混。
  • DUT 座A/B 同序 2×10：针 1–16 = A01…A16 / B01…B16，针 17–20 = NC/KEY（不挂 3.3V/GND）；20 芯排线红边 = Pin1。
  • 供电前端板从 J5-35/36 取 3.3V、33/34 回地；Rp=4.7kΩ 时 16 路 B 端上拉合计约 11.2 mA，上电前实测整板电流再定余量（V1.9 §7）。
  • 器件SN74LVC07A ×3（开漏）、SN74LVC14A ×3（施密特），各 18 通道用 16；剩余 2 路输入必须接固定电平，不许悬空。
  • 节奏先 1 路全链路验证（§7），再 4 路、16 路（§21 阶段验收，不跳步）；当前 RTL 默认 N_CH=4，P1 计划升 16。

上电前检查清单

按顺序过一遍，任何一项不过先别上电（对应 §27 复核规则与 §7 第一关）。

  • □转接线 Pin1 ↔ 板卡丝印对齐；万用表抽测：针 35/36 只通 3.3V、33/34 只通 GND，与任意 I/O 针互不通。
  • □A/B 座红边 = Pin1；针 17–20（NC/KEY）悬空，既不接 3.3V 也不接地。
  • □上拉到位：LVC07 输入 10 kΩ 安全上拉、B 端 Rp 默认 4.7 kΩ；LVC07/LVC14 未用的 2 路输入已接固定电平。
  • □共地：前端板 GND 测试点与 J5-33/34 导通（万用表蜂鸣档）。
  • □烧录 xunji_top_hw（自回环壳仅无 LVC14 调试用）；复位/空闲态 A 端 16 路全高，抽测 2–3 路确认。
  • □先 1 路：导通/拔线时 b_raw 变化与真值表一致（真实前端：导通=1、开路=0），再按 §21 扩 4 → 16 路。
代码怎么跑rtl/ · src/xunji/

模块数据流

从 b_raw 进来到 a_ctrl_n 出去是一个闭环；扫描一完成（scan_done）就组帧经 UART 送出。左列采集，右列出机。

组装关系：xunji_top_hw / xunji_top_loopback 是两个壳（差别只有极性那一行），内部都例化 xunji_core，由它把上图模块接起来。当前参数 N_CH=4、SCAN_SETTLE=500（5 μs）、GLITCH_CYCLES=50；V1.9 目标 16 路。

模块职责（它干什么）

xj_rst_sync外部 rst_n 一按立刻进复位（异步拉低），松开只在 100 MHz 时钟沿同步解除——按键毛刺进不了核心逻辑。
input_sync两级触发器接住异步 b_raw，防亚稳态传播；ASYNC_REG + 禁 SRL 属性写死在 RTL 里。
极性边界生产壳固定 b_conn=b_sync；回环壳 ~b_sync。全工程唯一反相点，核心之后再无极性处理。
glitch_filter每路独立：输入连续约 0.5 μs 不变才更新输出，滤掉接线毛刺与窄噪声，静态扫描拿的是稳态值。
topology_scanner六态 FSM 逐行扫描：拉低 A[a] → 等 SETTLE → 采一整行存矩阵 → 下一行；行全 0 置开路标志，末行发 done_pulse。
drive_controller把扫描意图落到管脚：只有当前行 a_ctrl_n=0，其余全释放；复位与空闲兜底 16'hFFFF。
timestamp_counter全局 64 位时间戳，每拍 +1（10 ns 颗粒）。与扫描并行运行，组帧时锁存低 8 位随帧上传。
uart_packet_txscan_done 一响就锁存矩阵+开路位+时间戳，10 拍逐字节算 CRC，再按 LOAD→ACK→DRAIN 三拍握手把 14 字节喂给 uart_tx（旧版会丢字节，已修）。
uart_tx字节按 8N1 逐位移出（DIV=868 拍/位）；busy 覆盖完整停止位，不会把停止位截成 30 ns。

关键代码逐行

帧组装与 CRC16

rtl/uart_packet_tx.v 摘录
// 线上共 14 字节：SOF(55 AA) + body(10) + CRC(2)；CRC 覆盖 Ver..Payload（不含 SOF）
// body 顺序 = Ver Type LenL LenH SeqL SeqH mat_lo mat_hi open ts0，除 SOF 外全小端
S_IDLE: begin
    if (trigger) begin                 // trigger = scan_done_pulse，扫描完成当拍
        mat_lo_r  <= matrix[7:0];     // 锁存 16×16 矩阵低字节（N_CH=4 时即整个矩阵）
        mat_hi_r  <= matrix[15:8];
        open_r    <= {4'b0, open_flags[N_CH-1:0]}; // 开路标志打包进载荷第 3 字节
        ts0_r     <= timestamp[7:0];  // 时间戳低 8 位随帧（全局计数一直在线）
        frame_seq <= seq_q;           // 帧序号：自由计数，首帧 0，≠物理先后
        seq_q     <= seq_q + 16'd1;
        crc_r     <= 16'hFFFF;        // CRC 初值 0xFFFF（CCITT-FALSE 冻结参数）
        pidx      < 4'd0;
        state     <= S_PREP;
    end
end

// 逐字节喂 CRC：10 拍把 body 算完，再去发帧（先算完再发，线上不会断档）
S_PREP: begin
    crc_r <= crc16_update(crc_r, body_byte(pidx));
    if (pidx == 4'd9) begin sidx <= 4'd0; state <= S_LOAD; end
    else pidx <= pidx + 4'd1;
end

// CRC-16/CCITT-FALSE 单字节更新：xor-first → 8 次左移，最高位为 1 则异或 0x1021
function [15:0] crc16_update;
    input [15:0] crc_in; input [7:0] data;
    begin
        c = crc_in ^ {data, 8'h00};        // 数据进高字节，与 protocol.py 逐行同构
        for (k = 0; k < 8; k = k + 1) begin
            if (c[15]) c = (c << 1) ^ 16'h1021; // 多项式 0x1021
            else        c = (c << 1);
        end
        crc16_update = c;
    end
endfunction

两级同步器

rtl/input_sync.v
// b_raw 来自线束前端，与 100 MHz sys_clk 完全异步——先过两级再进逻辑
// ASYNC_REG：让综合器把两级锁得紧邻、走普通布线；SHREG_EXTRACT=NO：禁止吸收成 SRL
(* ASYNC_REG = "TRUE", SHREG_EXTRACT = "NO" *) reg [WIDTH-1:0] stage1;
(* ASYNC_REG = "TRUE", SHREG_EXTRACT = "NO" *) reg [WIDTH-1:0] stage2;

always @(posedge clk) begin
    if (rst) begin
        stage1 <= {WIDTH{1'b0}};
        stage2 <= {WIDTH{1'b0}};
    end else begin
        stage1 <= d_in;    // 第一级：只求接住信号，亚稳态在此消散
        stage2 <= stage1;  // 第二级：干净采样，此后才允许进核心逻辑
    end
end

assign d_out = stage2;   // 16 位各自独立同步，不当作需要同拍一致性的总线

扫描节拍

rtl/topology_scanner.v 摘录（FSM 主干）
// 一轮扫描 = 每行四步：拉低 → 等稳 → 采样 → 换行；输入 b_filtered 已是 b_conn 语义
S_DRIVE: begin
    drive_en    <= 1'b1;
    drive_level <= 1'b0;   // 0 = 拉低：本行 A 端经 LVC07 把线束按到地
    scan_idx    <= row;    // drive_controller 只响应这一行，其余全释放
    wait_cnt    <= 16'd0;
    state       <= S_WAIT;
end

S_WAIT: begin
    if (wait_cnt >= SETTLE)  // SETTLE=500 拍 = 5 μs，等 LVC07/线束/Rp 电平落定
        state <= S_SAMPLE;
    else
        wait_cnt <= wait_cnt + 16'd1;
end

S_SAMPLE: begin
    conn_matrix[row*N_CH +: N_CH] <= row_bits;  // 整行写入矩阵（row-major：bit=a*N+b）
    open_flags[row]               <= ~|row_bits; // 行内全 0 → 这一路 A 无连接
    state <= S_NEXT;
end

S_NEXT: begin
    if (row == N_CH - 1) state <= S_DONE;       // 末行 → 收尾：释放驱动、发 done_pulse
    else begin row <= row + 4'd1; state <= S_DRIVE; end
end

上位机组帧（Python 对应物）

src/xunji/protocol.py
def crc16_ccitt_false(data: bytes) -> int:
    crc = _CRC_INIT                    # 0xFFFF，与 RTL 端 crc_r 初值一致
    for byte in data:
        crc ^= byte << 8               # xor-first：数据进高字节（同 RTL c = crc ^ {data,0}）
        for _ in range(8):
            if crc & 0x8000:         # 最高位为 1 → 左移后异或多项式 0x1021
                crc = ((crc << 1) ^ _CRC_POLY) & 0xFFFF
            else:
                crc = (crc << 1) & 0xFFFF
    return crc

def build_frame(version, frame_type, sequence, payload) -> bytes:
    body = (bytes((version, frame_type))        # Ver Type 在最前
            + len(payload).to_bytes(2, "little") # Len 小端（V1.9 §17）
            + sequence.to_bytes(2, "little")    # Seq 小端
            + payload)                           # CRC 覆盖 Version..Payload
    crc = crc16_ccitt_false(body).to_bytes(2, "little") # CRC 小端收尾
    return SOF + body + crc                      # 55 AA 开头 → 解析端先对 SOF 再验 CRC

极性与安全红线

  • 复位即释放：drive_controller 复位态 a_ctrl_n = 16'hFFFF，扫描空闲同样全 1——任何情况下不许在复位期间拉低 A 端。
  • 全工程唯一反相：xunji_top_loopback.v 里 b_conn = ~b_sync 一行；生产壳 xunji_top_hw.v 固定 b_conn = b_sync。
  • 核心只认 b_conn：topology_scanner、glitch_filter 不读 b_raw，也不做任何极性处理。
  • 单时钟铁律：只有 100 MHz sys_clk，节拍一律 clock-enable；b_raw / uart_rx 必须两级同步才进逻辑。
  • 未用通道：3 片 LVC07/LVC14 各剩 2 路，输入接固定电平（LVC07 接高保持释放），不许悬空。
  • 电源红线：J5-35/36=3.3V、33/34=GND 不进 XDC；转接线装配后按 Pin1 逐线核对再上电（V1.9 P068）。
